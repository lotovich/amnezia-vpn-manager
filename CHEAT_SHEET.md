# 📋 AmneziaVPN Bot — Шпаргалка администратора

Здесь собраны основные команды для управления вашим VPN-ботом на сервере.

## 1. 🚀 Вход на сервер
Схема каскадная: клиенты → **российский сервер** (AmneziaWG + бот + БД) → туннель через Cloudflare → **выход за границей** (только Xray).

| Роль | Адрес | SSH |
|---|---|---|
| Вход, Россия (Selectel) | `136.234.4.79` | `ssh -i ~/.ssh/amnevpn -p 22222 root@136.234.4.79` |
| Выход (Tube-Hosting) | `5.253.246.42` | `ssh -i ~/.ssh/amnevpn -p 22222 root@5.253.246.42` |

Только по ключу `~/.ssh/amnevpn`, пароли отключены. Домен `amnevpn.duckdns.org` должен указывать на российский сервер. Домен выхода `go.tebetochno.top` живёт в Cloudflare (туннель `exit-ams`). Подробности и проверка: `docs/cascade.md`.

Старый сервер `89.125.131.60` (JustHost) остаётся с MTProto-прокси и kaist-bot.

## 2. 🔄 Обновление бота
Если вы внесли изменения в код (на компьютере) и хотите обновить бота на сервере:

1. **Зайдите в папку проекта**:
   ```bash
   cd /root/amnezia-vpn-manager
   ```

2. **Получите свежий код**:
   ```bash
   git pull
   ```

3. **Перезапустите контейнеры** (с пересборкой):
   ```bash
   docker compose up -d --build
   ```
   *(Флаг `-d` означает "detach" — запустить в фоне. Консоль освободится, а бот будет работать).*

## 3. 🛠 Полезные команды

### Посмотреть статус (работает ли?)
```bash
docker compose ps
```
Вы должны увидеть `Status: Up` для сервисов `vpn` и `bot`.

### Посмотреть логи (что происходит?)
Следить за логами бота в реальном времени:
```bash
docker compose logs -f bot
```
*(Нажмите `Ctrl + C`, чтобы выйти из просмотра логов)*.

### Перезагрузить всё
```bash
docker compose restart
```

### Остановить всё
```bash
docker compose down
```
