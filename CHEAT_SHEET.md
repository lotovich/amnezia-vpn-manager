# 📋 AmneziaVPN Bot — Шпаргалка администратора

Здесь собраны основные команды для управления вашим VPN-ботом на сервере.

## 1. 🚀 Вход на сервер
Откройте Терминал на Mac и введите:
```bash
ssh root@<IP_ВАШЕГО_СЕРВЕРА>
```
*(Вам нужно будет ввести пароль от сервера, символы пароля не отображаются при вводе)*.

---

## 2. 🔄 Обновление бота
Если вы внесли изменения в код (на компьютере) и хотите обновить бота на сервере:

1. **Зайдите в папку проекта**:
   ```bash
   cd amnezia-vpn-manager
   ```

2. **Получите свежий код**:
   ```bash
   git pull
   ```

3. **Перезапустите контейнеры** (с пересборкой):
   ```bash
   docker compose up -d --build
   ```
   *(Флаг `-d` означает "detach" — запустить в фоне. Консоль освободится, а бот будет работать).*

---

## 3. 🛠 Полезные команды

### Посмотреть статус (работает ли?)
```bash
docker compose ps
```
Вы должны увидеть `Status: Up` для сервисов `vpn` и `bot`.

### Посмотреть логи (что происходит?)
Следить за логами бота в реальном времени:
```bash
docker compose logs -f bot
```
*(Нажмите `Ctrl + C`, чтобы выйти из просмотра логов)*.

### Перезагрузить всё
```bash
docker compose restart
```

### Остановить всё
```bash
docker compose down
```
