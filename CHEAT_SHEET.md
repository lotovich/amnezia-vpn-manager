## 1. 🚀 Вход на сервер
Сервер: **5.253.246.42** (Tube-Hosting, Германия). SSH работает на порту **22222**, только по ключу `~/.ssh/amnevpn` (вход по паролю отключён).

```bash
ssh -i ~/.ssh/amnevpn -p 22222 root@5.253.246.42
```

Домен `amnevpn.duckdns.org` должен указывать на этот IP (меняется на duckdns.org).

## 2. 🔄 Обновление бота
Если вы внесли изменения в код (на компьютере) и хотите обновить бота на сервере:

1. **Зайдите в папку проекта**:
   ```bash
   cd amnezia-vpn-manager
   ```

2. **Получите свежий код**:
   ```bash
   git pull
   ```

3. **Перезапустите контейнеры** (с пересборкой):
   ```bash
   docker compose up -d --build
   ```
   *(Флаг `-d` означает "detach" — запустить в фоне. Консоль освободится, а бот будет работать).*

## 3. 🛠 Полезные команды

### Посмотреть статус (работает ли?)
```bash
docker compose ps
```
Вы должны увидеть `Status: Up` для сервисов `vpn` и `bot`.

### Посмотреть логи (что происходит?)
Следить за логами бота в реальном времени:
```bash
docker compose logs -f bot
```
*(Нажмите `Ctrl + C`, чтобы выйти из просмотра логов)*.

### Перезагрузить всё
```bash
docker compose restart
```

### Остановить всё
```bash
docker compose down
```
